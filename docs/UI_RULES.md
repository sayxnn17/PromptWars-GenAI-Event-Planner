# As of now we are going to make a UI purely based on HTML, CSS and JS - vanilla versions of everything.

# Rules:
- All content is to be centered unless specified.
- Wherever the user is made to select any option or answer any question, there the instructions must be very clear.
- All options must be represented by boxes with rounded corners, and whenever the user selects an option, that option must be a bit highlighted, using let's say a very slight greyish background, only for that option-box.
- The lists for options on the "Overall Style" page and "Set Priority" page are listed in the LISTS.md file.

## 1. The landing page:
The landing page must be very simple and straightforward. It must contain the name "AI Event Planner" at the top with a button "Start Planning" at the vertical center of the page.

## 2. The event type selection page:
This is the page where the user selects the type of event that they are going to plan. There must be exactly 3 options on this page: Birthdays, Weddings, Community Events.

## 3. The name + date + location page:
This is meant to ask and get the name, date, location and indoor/outdoor preference from the user.

## 4. Budget page:
This page is meant to ask the user for their total budget for the event.

## 5. Overall Style selection page:
For each type of the event, there will be a defined list of options, describing the various styles in which the event can be hosted. Thus depending on the type of event that the user has selected previously, they must be displayed the list of options from which the user has to select one type.

## 6. Set priority page:
Here also the user is showed various options from where they get to choose 3 options. The first one they choose is the option with highest priority, followed by the one clicked next, then the last one. If the user deselects the first option after making the second choice then the second one becomes the first choice and like this...

## 7. Customizations page:
This asks the user for any specific customizations/rules that need to be followed while planning the event. These instructions must be accepted into a text field. Also at the lower part of this page, there must be a "Generate" option.
